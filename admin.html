How to publish

1. Edit or add your vehicles and upload pictures. 2. Click Publish Inventory File to download inventory.json. 3. Open your GitHub repository, choose Add file → Upload files, place inventory.json at the repository root and commit. 4. Refresh your public website after GitHub Pages deploys.

Photos are compressed and embedded in the exported inventory file. For large inventories, use cloud storage and a backend instead.
