# Elite Motors · Website and No-Code Inventory Editor

## Files
- `index.html` — public dealership site.
- `admin.html` — browser-based inventory editor; no account or secure authentication.
- `inventory.json` — public car inventory, generated by the editor after clicking Publish Inventory File.
- `assets/` — logo files.

## Workflow
1. Open `admin.html` in Chrome (preferably through a local server such as VS Code Live Server or GitHub Pages).
2. Add cars and images; select Save. Drafts are saved in your current browser only.
3. Click `Publish Inventory File` to download `inventory.json`.
4. Upload that file to the **root** of your GitHub repository `rahman1275/elitemotors` on the `main` branch and commit it. If existing, overwrite it.
5. Refresh the public site once GitHub Pages deploys; the site will read all car listings from the uploaded JSON.

## Critical limitations
- **No security:** `admin.html` is a public static page and should not be treated as a private admin account. Do not upload private customer data.
- The editor does **not** auto-publish to GitHub. Export + commit are necessary.
- Browser drafts are device/browser-specific and can disappear if browser data is cleared. Regularly back up `inventory.json`.
- Customer enquiry forms on the current public site are local browser demos, **not** a shared dealership inbox.
- Photos are embedded into exported JSON for portability; for many cars/photos, use a proper CMS and cloud object storage.
- The original sample inventory shows until you publish your first `inventory.json`. Export an empty inventory to hide all demo cars.
- This release is designed for content management, not production-grade authentication or payments.
