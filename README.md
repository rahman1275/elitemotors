# Elite Motors — used-car marketplace website

A responsive static website prototype for an Indian pre-owned vehicle dealership.

## Features
- Premium blue / black / white storefront, mobile navigation and hero search
- Example car inventory with search, make, budget, fuel, gearbox, city, category and sorting
- Car detail modal, favourites, finance EMI illustration and test drive / buyer enquiry form
- Sell-your-car form with photo uploads (images are resized in-browser)
- Locally saved demo listings / enquiries with delete and CSV enquiry export

## Run / publish
1. Download and unzip the package.
2. Open `index.html` in your browser to preview.
3. Create a GitHub repository and upload `index.html` into its root.
4. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Replace all sample vehicles, prices and placeholder photos with your own verified dealership inventory.

## IMPORTANT: demo limitations
This is a **front-end demo**. Uploaded images, new listings, saved cars and submitted enquiries are stored only in the visitor's own browser via localStorage; they are NOT shared or transmitted to the dealership. The car photos and example specifications/prices are illustrative, not actual sale offers. The website is not a secure admin system and has no user authentication, real booking confirmation, payment checkout, loan processing, inventory database or warranty assurances.

For a production multi-user marketplace, add a secure backend (e.g. Supabase/Firebase), authenticated admin dashboard, shared database, object storage for vehicle images, server-side form submission/email notifications, anti-spam and moderation. Configure your real showroom address, email, phone and WhatsApp contact information. Do not collect ID documents, card details or loan applications using this static prototype.
